# Independent production review — feature/homepage-production

Reviewed 18/08/2026 against `acceptance/DEFINITION-OF-DONE.md` and `CLAUDE.md`, using the running production build at http://localhost:3113 (Playwright/Chromium headless, curl, axe-core 4.13). Read-only review; no source edited.

**Summary:** 0 blockers, 6 major, 8 minor, 6 notes. All sampled public routes return 200 with one h1, unique titles/descriptions, no third-party requests, no cookies, no horizontal overflow at 320/640 px and no console errors; keyboard, skip link, forms (with and without JS), reduced motion, JSON-LD and the client bundle are clean. The material problems: the indexing switch disagrees between build and runtime, occupied homes expose EPC-register-precise facts, "Bills — Not included" is unverified, unknown-slug 404s ship blank server HTML, Open Graph is generic on every page except articles, and same-street property pages share identical titles.

## Checks that passed

- Routes: 14 HTML routes (12 static + property + article) plus /sitemap.xml and /robots.txt all 200; exactly one h1 per page; 14/14 unique `<title>` and meta descriptions in the sampled set; `lang="en-GB"`; one `<main>`; navs labelled ("Primary", "Footer — Explore/Company/Legal", "Breadcrumb", "On this page", "Results view", "Article categories").
- Layout: no horizontal overflow at 320 px or 640 px on any of the 14 pages (`scrollWidth === clientWidth`); axe-core WCAG 2.x A/AA + best-practice: 0 violations on 12 of 13 pages at both 1280 and 375 px (one moderate landmark-unique on /landlords, above).
- Network/privacy: zero requests to any host other than localhost:3113 on every page (fonts, images, scripts same-origin); zero cookies set; no analytics.
- Links: 71 unique internal hrefs crawled from all pages — all 200; external links limited to wa.me, GOV.UK, peterborough.gov.uk, Facebook, Instagram (socials are in brief/BUSINESS-FACTS-AND-COPY.md).
- Facts: no full postcode (`PE\d\s?\d[A-Z]{2}`), no house numbers, no email address, no telephone other than WhatsApp 07300 856675 (plus the National Gas Emergency 0800 111 999 safety line on /maintenance), no "24/7", no "guaranteed" claim (only "We never present a guaranteed rent"), no reviews/testimonials/awards/ratings/memberships, no opening hours (contact page: "to follow"), no "Lets Move". Prices on / and /tenants are the labelled deposit-cap worked example (£1,000 pcm → £1,154 / £231 / £2,154) plus the one listed rent. Privacy/cookies/terms carry "Draft placeholder — not yet reviewed for publication".
- Keyboard: 45/45 tab stops on /, 45/45 on /properties, 41/41 on /maintenance show a visible focus ring (`outline: solid 3px`, ink, or cream on dark surfaces); no outline removed anywhere. Skip link is the first tab stop, visible when focused, target `#main-content` exists and the next Tab lands inside main. "Skip the house story" moves focus to `h2#after-story[tabindex=-1]`. Mobile menu (375 px): `aria-expanded` toggles, panel `role="dialog"`, Tab stays inside, Escape closes and returns focus to the "Open menu" button.
- Forms (/maintenance "Report a repair"): empty submit → `role="alert"` summary receives focus ("Please check these 5 fields"), 5 links to existing field ids; each invalid control has `aria-invalid="true"` and `aria-describedby` pointing at existing hint/error ids. Valid submit → `data-form-status="ready"` panel receives focus and states "Online delivery from this website is not active yet, so nothing has been sent"; WhatsApp link is `https://wa.me/447300856675?text=…` containing the composed message. Identical behaviour with JavaScript disabled (plain POST re-render). The server action does not log submissions.
- Reduced motion (`prefers-reduced-motion: reduce`) on /: 0 `<canvas>`, 0 `<video>`, no `.glb/.mp4/.webm` requests; static chapter JPEGs shown; h1 and CTAs render first. Normal mode: one canvas inside `div[aria-hidden="true"]`, `tabindex="-1"`, `pointer-events: none`; scroll stays native (CSS sticky, no pin).
- No-JS: homepage serves the full neutral story HTML (22 chapter headings) with `[data-needs-js]` controls hidden; /properties?view=map renders the schematic SVG map plus the full list.
- Properties: schematic SVG map (no MapTiler key → static fallback, no third-party tiles), list duplicates map info, useful empty state ("No homes match those filters… Nothing is hidden"), demo listings not served (portfolio repository bound), map pins are area-approximate.
- Bundles: `.next/static` contains no "SANITY_API", "FORM_DELIVERY", "MAPTILER", no `NEXT_PUBLIC_*` values, no `process.env.*`, no token-like strings; only reference hosts are w3.org/nextjs.org/react.dev/github.com/facebook/instagram/wa.me.
- Structured data: every `application/ld+json` on /, /tenants, /landlords, /maintenance, the article and the property page parses; the RealEstateAgent object contains only name, description, url, foundingDate "2012", areaServed Peterborough and sameAs (FB/IG) — no telephone, email, address, openingHours or ratings; FAQPage and Article objects well-formed.
- OG images: `/opengraph-image` and article `opengraph-image` return 200 image/png; `twitter:card` summary_large_image present.
- robots.txt disallows /experiments/ and /api/; /experiments pages carry route-level `noindex, nofollow`; sitemap excludes experiments and the (all-draft) articles.
