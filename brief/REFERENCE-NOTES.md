# Reference notes — borrow the principles, not the sites

## Igloo

Reference: https://www.igloo.inc/

Borrow:

- One memorable object acting as the story spine
- Strong pacing and chapter transitions
- Purposeful negative space
- A cinematic sense of arrival
- The feeling that a scene changes meaning as the visitor scrolls

Do not borrow:

- An all-WebGL interface
- Body copy rendered in a canvas
- Hidden or tiny navigation
- Forced/infinite scrolling
- A one-viewport document that search engines or assistive technology cannot understand
- Any branded shapes, assets, copy or code

Red Brick adaptation: a stylised brick house assembles and reveals how Prepare, Let, Manage and Care connect.

## Resider

References:

- Homepage: https://resider.ca/home
- Property map/list: https://resider.ca/
- Valuation journey: https://resider.ca/sell

Borrow:

- Clear visitor categorisation
- A serious map/list property workspace
- Progressive disclosure on property details
- Calm appraisal flow
- Useful calculations and context
- Clear mobile List/Map switching

Do not borrow:

- Purchase-specific mortgage or sales features
- Excessive filters before Red Brick has enough inventory
- Sign-in gates at launch
- AI search before the underlying listing/data system is reliable
- Crime heatmaps or neighbourhood ranking
- Any copyrighted content, imagery, code or exact layout

Red Brick adaptation:

- “Buy” becomes **Properties to rent**
- “Sell” becomes **What could your property rent for?**
- Mortgage costs become **Move-in costs**
- Market context becomes a carefully sourced Peterborough rental/area report

## Visual difference

The result should not look like either reference. Use the Red Brick brick/cream palette, British residential imagery, rounded but restrained surfaces, readable typography and an original house/story composition.
