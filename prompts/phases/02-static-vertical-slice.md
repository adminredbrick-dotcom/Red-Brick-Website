# Phase 2 — complete static vertical slice

Build the polished static version of the homepage plus one property-search page, one property-detail page and one illustrative rental-report result.

Homepage must include the hero, audience choice, trust introduction, static house-story fallback, map/list preview fallback, landlord and tenant tools, maintenance process, insights and closing CTAs. It must be good enough to use before advanced motion exists.

Use the supplied starter copy and clearly marked illustrative property records. Do not invent business proof or live availability. Do not imitate Igloo or Resider literally.

Done when:

- The static experience looks intentional at 320, 375, 768, 1024 and 1440px.
- Landlord/Tenant choice works and both routes remain visible.
- Demo listings cannot be mistaken for genuine properties.
- Reduced-motion and no-JavaScript content remain coherent.
- Tests, build and browser/console inspection pass.

Report evidence and stop for approval before Phase 3.
