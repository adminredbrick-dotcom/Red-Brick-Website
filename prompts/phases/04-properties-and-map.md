# Phase 4 — properties and Peterborough map

Build `/properties` and `/properties/[slug]` through a typed replaceable repository adapter using the supplied illustrative data.

Add the MapTiler/MapLibre experience with synchronised property cards and markers, clustered results, approximate public locations, accessible controls and a mobile List/Map switch. Default to list/2D usefulness. If no map key is configured, show a complete list/static fallback instead of an error.

Do not reveal restricted address/access fields. Do not keep the R3F scene rendering while the map is active.

Done when:

- Filters, empty results, selection and map/list synchronisation work.
- Keyboard and screen-reader users can access equivalent listing information outside the canvas.
- Wheel zoom is not a scroll trap.
- Every sample property states “Illustrative example — not currently available.”
- Demo properties are excluded from genuine production indexing.
- Missing-map-key and data-error states are verified.

Report evidence and stop before Phase 5.
