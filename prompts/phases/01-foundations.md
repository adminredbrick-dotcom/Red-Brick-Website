# Phase 1 — foundations

Implement the approved Phase 0 architecture now.

Create the Next.js foundation, brand tokens, fonts, responsive grid, header, navigation, footer, buttons, cards, form controls, central typed business configuration and global accessibility behaviour.

Create every approved route with semantic placeholder sections. Do not add the advanced 3D scene, scroll film or live map yet. Preserve all handoff files. Add an owner-decision register and `.env.example` without secrets.

Use the locked stack and do not install overlapping UI or animation frameworks.

Done when:

- The project installs, lints, type-checks and builds.
- Every route and mobile navigation works.
- Keyboard navigation, visible focus, contrast and 320px reflow have been inspected.
- No unconfirmed business fact is exposed as real content.

At the end report changed files, assumptions, commands/tests and results, screenshots/inspection evidence, and remaining review items. Stop for approval before Phase 2.
